# Problem Solving & Decision Making - Interactive Microlearning

Modul pembelajaran interaktif berbasis web untuk **Digital Leadership Program (DLDP)**: *Problem Solving & Decision Making*.

## 🌟 Fitur Utama
- **11 Unit Interaktif Lengkap**: 3D Flip Cards, Diagnostic Tabs, Fishbone Ishikawa (4M+1E) & 5-Whys Stepper, Drag & Drop Gamified Sorter, 2x2 Decision Matrix Simulator, Corrective Action 3-Phase Stepper, Cycled PDCA Agile Stepper, Branching Scenario Dilemma (suara Dian), Post-test Evaluasi Sumatif (Confetti effect), dan Action Plan Canvas.
- **Audio Voiceover Studio**: 11 file audio voiceover tersinkronisasi per unit (`unit_00.mp3` s/d `unit_10.mp3`).
- **Tactile Web Audio SFX**: Audio synthetis tanpa latensi (click, success, error, fanfare).
- **Desain Modern (Spike Ascent Theme)**: Palet harmonis (`#1A1A1A`, `#E01A4F`, `#4C8DF1`, `#F2F2F2`), tipografi **Plus Jakarta Sans**, dan **Google Material Symbols**.
- **SAP SuccessFactors LMS Ready**: Dilengkapi universal runtime adapter SCORM 1.2 & SCORM 2004 (`imsmanifest.xml` dan file siap impor).
